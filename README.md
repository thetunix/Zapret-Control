# Zapret Control Center

Electron-панель управления для локального набора
[`Flowseal/zapret-discord-youtube`](https://github.com/Flowseal/zapret-discord-youtube)
на Windows. Приложение помогает запускать, останавливать, тестировать и обновлять
`zapret` без ручной работы с `.bat`-файлами и командной строкой.

## Возможности

- запуск, остановка и перезапуск `zapret/bin/winws.exe` из графического интерфейса;
- выбор конфигураций `zapret/general*.bat`;
- установка Windows-службы `zapret` для запуска без UAC при каждом старте;
- автозапуск приложения вместе с Windows;
- автоматическое включение лучшего найденного конфига;
- проверка и применение обновлений `zapret`;
- тестирование конфигов по целям из `zapret/utils/targets.txt`;
- редактирование пользовательского списка доменов `zapret/lists/list-general-user.txt`;
- логи, трей-режим, темы интерфейса и настройка игрового фильтра.
- мониторинг доступности YouTube, Discord и контрольного сайта по HTTPS;
- умное автопереключение на ранее протестированную стратегию с проверкой результата и откатом;
- диагностика файлов, службы Windows, DNS и соединения с подтверждаемыми исправлениями;
- визуальный конструктор пользовательских `general (CUSTOM ...).bat` на основе существующих стратегий.
- отдельная вкладка Telegram Proxy для скачивания, проверки SHA-256 и запуска официального TG WS Proxy от Flowseal;
- анимированные состояния «Отключено → Подключение → Подключено» с учётом настройки уменьшения движения Windows.

## TG WS Proxy (Telegram)

На вкладке **Telegram Proxy** нажмите «Скачать и запустить». Приложение загрузит
`TgWsProxy_windows.exe` из [официального релиза Flowseal](https://github.com/Flowseal/tg-ws-proxy/releases),
проверит SHA-256, предоставленный GitHub, и сохранит программу в локальных данных
Zapret Control Center. Скачивание происходит **только по нажатию кнопки**.

TG WS Proxy — отдельное приложение для Telegram Desktop, оно сворачивается в
системный трей. Чтобы подключить Telegram, нажмите правой кнопкой мыши на
значке TGWS и выберите «Открыть в Telegram». TGWS не подменяет системный VPN
и не обрабатывает трафик других приложений.

Кнопка «Остановить» управляет только TGWS, запущенным через Control Center.
Если прокси запущен самостоятельно, завершите его через меню трея. Повторная
загрузка/обновление запрещена, пока процесс работает, чтобы не переписывать
исполняемый файл. Исходный код TGWS опубликован под лицензией MIT.

Сборка beta для Windows включает `winws.exe` из официального релиза
Flowseal zapret-discord-youtube 1.10.4. GitHub Actions проверяет SHA-256 архива
перед добавлением бинарника в установщик; `winws.exe` не хранится в Git.

## Мониторинг и умное переключение

На вкладке **Мониторинг** можно запустить проверку вручную либо оставить фоновый
опрос (раз в две минуты). Проверяется HTTPS-ответ сайта; успешная проверка не
гарантирует работу видеопотока YouTube или голосового канала Discord.

Умное переключение по умолчанию **выключено**. Для его использования:

1. На вкладке **Тесты** проверьте стратегии, чтобы сформировать список подходящих вариантов.
2. На вкладке **Мониторинг** включите «Умное автопереключение».
3. Если YouTube/Discord недоступен в двух последовательных проверках, а контрольный
   сайт Google отвечает, программа может попробовать другую проверенную стратегию.

После смены конфигурации доступность проверяется повторно. Если улучшения нет,
возвращается предыдущий конфиг; новые попытки ограничены интервалом в 20 минут.
Внешние процессы `winws.exe` автоматически не перенастраиваются. Переключение
установленной службы без прав администратора не выполняется в фоне: программа
предложит выбрать конфиг вручную.

## Диагностика и конструктор

В **Диагностике** проверяются ключевые бинарники, списки, текущая стратегия,
процесс, служба, DNS и HTTPS. Небольшие исправления (восстановление отсутствующих
списков, запуск zapret, установка службы, выбор базового конфига, отключение
игрового фильтра) требуют отдельного подтверждения. Сброс сети, изменение DNS
и отключение антивируса автоматически не производятся.

В **Конструкторе** выберите исходный конфиг, измените порты, DPI desync,
повторы или TLS fake и проверьте сформированный BAT. Сохранение создаёт отдельный
`general (CUSTOM Имя).bat`; исходный файл не перезаписывается. Остальные параметры
базовой стратегии сохраняются без изменений. Для записи в папку установки
Windows могут понадобиться права администратора.

## Как работает режим без постоянного UAC

Windows не позволяет приложению тихо получить права администратора при каждом
запуске. Поэтому Control Center использует нормальную схему через службу:

1. Откройте приложение обычным способом.
2. Перейдите в `Настройки` -> `Служба Windows`.
3. Нажмите `Установить`.
4. Подтвердите UAC один раз.

После этого создается служба `zapret`, которая запускает `winws.exe` с нужными
правами. Обычные кнопки включения и выключения используют уже установленную
службу, поэтому UAC больше не появляется при каждом запуске.

Если выбран другой конфиг, приложение переустановит службу с новыми аргументами.
Для этого снова потребуется подтверждение UAC, потому что меняется системная
служба Windows.

## Требования

- Windows 10 или Windows 11;
- Node.js 22.12+ для разработки и сборки;
- установленный `npm`;
- папка `zapret/` рядом с приложением, включая `bin/winws.exe` и `service.bat`.

## Запуск для разработки

```powershell
npm install
npm start
```

Явный запуск с запросом прав администратора:

```powershell
npm run start:admin
```

Обычный `npm start` не вызывает UAC автоматически. Это удобно для разработки
интерфейса и не закрывает dev-сессию при отказе от повышения прав.

## Сборка

```powershell
npm run build
```

Готовый NSIS-инсталлятор появляется в папке `dist/`.

Проверки логики конструктора и выбора стратегий:

```powershell
npm test
```

## Структура

```text
.
├── src/
│   ├── main.js       # Electron main process и управление zapret
│   ├── preload.js    # безопасный IPC bridge
│   ├── renderer.js   # логика интерфейса
│   ├── index.html    # окно приложения
│   └── styles.css    # стили интерфейса
├── zapret/           # локальные файлы Flowseal zapret-discord-youtube
├── package.json
└── README.md
```

## Релиз

Версия задается в `package.json`. Перед релизом:

```powershell
npm run build
```

Основной артефакт для публикации:

```text
dist/Zapret Control Center Setup <version>.exe
```

## Важно

Проект является графической оболочкой для локального `zapret` и не является
официальным релизом `Flowseal/zapret-discord-youtube`.
