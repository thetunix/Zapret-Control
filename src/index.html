Telegram за три шага

  1. 01

    Скачай и запустиПриложение TG WS Proxy появится в системном трее.

  2. 02

    Открой проксиПравый клик по иконке TGWS → «Открыть в Telegram».

  3. 03

    ПодключисьTelegram добавит локальный MTProto-прокси. Подтверди подключение.

Отдельно от Zapret
TG WS Proxy не заменяет VPN и не переключает соединения остальных приложений. Используй кнопку в трее TGWS для настройки Telegram.

Ожидание проверки…

Проверяется HTTPS-ответ сайтов. Работа видео, CDN и голосовых каналов отдельно не гарантируется.

Результаты подбора

Альтернативы берутся из тестов на вкладке «Тесты». При смене службы Windows могут понадобиться права администратора.

Диагностика

Проверка файлов, службы, DNS и соединения

Исправления выполняются только после подтверждения. Системные DNS и сетевые настройки не сбрасываются.

Запустите диагностику, чтобы увидеть результат.

Конструктор

Создание своей стратегии без редактирования BAT вручную

Исходный BAT не изменяется. Редактируются правила TCP/UDP, DPI desync, повторы и TLS fake; остальные параметры сохраняются. Для записи в защищённую папку установки могут потребоваться права администратора.
